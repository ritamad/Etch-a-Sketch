# Etch-a-Sketch

 Live demo: https://ritamad.github.io/Etch-a-Sketch/

Etch A Sketch is a browser-based drawing application built as part of The Odin Project.
It allows users to draw on a customizable grid by interacting with the mouse, with features implemented using HTML, CSS, and vanilla JavaScript.
The project focuses on DOM manipulation, event handling, and dynamic grid generation.
